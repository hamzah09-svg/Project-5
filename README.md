# Project 5 – Product Page
 
A responsive-style product page built with plain **HTML and CSS**, created to practise web fundamentals: page structure, layout, and styling.
 
## Features
 
- Product image section with variant images
- Product header and price section
- Variant selection section
- Size selector (UK 6, 7, 8, 9) with a size guide heading
- "Add To Cart" and "Wishlist" buttons
## Tech Used
 
- HTML5
- CSS3
## Project Structure
 
```
Project-5/
├── images/        # product and variant images
├── index.html     # page structure
└── style.css      # page styling
```
 
## How to Run
 
1. Clone the repository:
```
   git clone https://github.com/hamzah09-svg/Project-5.git
```
2. Open the `Project-5` folder.
3. Open `index.html` in your browser (or use the **Live Server** extension in VS Code).
## What I Practised
 
- Structuring a page with semantic sections (`main`, `section`, `div`)
- Organising content with class names for styling
- Styling layouts and buttons with CSS
